# TCS-Annual-Report-Gen-AI-Chatbot-RAG-Based-
Built a Generative AI chatbot using Python, LangChain, Hugging Face embeddings, FAISS, and OpenAI LLMs to answer questions from the TCS Annual Report PDF. The application uses Retrieval-Augmented Generation (RAG) to retrieve relevant document chunks and generate context-based answers through a Flask REST API, testable using Postman.
